Вход владельца

GitHub не разрешает вход «в один клик» со статического сайта (CORS), поэтому используется персональный токен с правом записи в этот репозиторий. Токен хранится только в вашем браузере и отправляется только на api.github.com.

  1. Откройте создание fine-grained токена
  2. Repository access → Only select repositories → PinFilmBoard
  3. Permissions → Contents: Read and write
  4. Скопируйте токен и вставьте сюда

Вы вошли как — права редактирования активны.
