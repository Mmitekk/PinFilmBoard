## Как продолжить

**Окружение:** Node 24 (только встроенные модули для tools/*), любой современный браузер. Зависимостей нет, сборки нет — vanilla JS (ES5-стиль IIFE, как PinVideoBoard/PinRefBoard).

## Задача 3 — 409 при удалении + сломанная сортировка «Сначала новые» — 2026-11-22

### Что сделано
- **409**: причина — GET содержимого GitHub API кэшировался браузером (до минуты), PUT шёл со старым sha. В `js/api.js`: `cache: 'no-store'` для всех запросов + `putWithRecovery` (перечитывание файла при 409: noop при совпадении контента, диалог конфликта если менял кто-то другой, повтор со свежим sha; для overwrite — всегда повтор). Проблема у пользователя уже разрешилась повторами (живой db.js содержит его удаление), теперь — автоматически.

Компаратор теперь через `Date.parse`; все 33 старых addedAt мигрированы в ISO; в `tools/import-pinterest.mjs` добавлен isoDate.
- **Masonry**: CSS columns наполняет колонку сверху вниз — «новые» визуально уезжали вбок. Переведено на round-robin колонки (`renderGallery` + `.m-col` flex), чтение слева направо как в Pinterest, пересчёт колонок на resize. Проверено: верхний ряд = 5 самых новых (topRowCorrect:true).
- Бонус: «Брат 2» (новейшая карточка пользователя) — перезаполнено описание/постер/год (поиск попал в статью «URL»).

### Ответ пользователю
> 1) Починил. 409 — это «sha устарел»: GitHub API кэшировал чтение файла до минуты, и удаление уходило со старым отпечатком. Теперь чтение всегда без кэша, а при 409 сайт сам перечитывает файл и повторяет операцию (или честно покажет диалог конфликта, если файл менял кто-то ещё). Ваше удаление, кстати, в итоге прошло — в живых данных карточки уже нет. Правка заработает на живом сайте после push + F5.
> 2) Тоже починил, причин было две. Первая: у карточек из Pinterest даты были в формате «Wed, 26 Aug 2026…», а сайт пишет «2026-11-22…» — сравнение строк таких форматов перемешивало всё, и ваши новые карточки уезжали вниз. Теперь даты сравниваются правильно, а старые приведены к одному формату. Вторая: сетка раскладывала карточки сверху вниз по колонкам (CSS columns), из-за чего верхний ряд выглядел перемешанным — переработал на раскладку слева направо, как в настоящем Pinterest. Проверил: верхний ряд — это 5 самых свежих (Брат 2, Паук-Нуар, Пленницы, Одержимая, Братья). Заодно заметил, что у «Брат 2» описание подтянулось из статьи про URL — перезаполнил правильным (описание, постер, 2000). Обновление — после push + F5.
