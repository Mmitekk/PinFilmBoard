## Как продолжить

**Окружение:** Node 24 (только встроенные модули для tools/*), любой современный браузер. Зависимостей нет, сборки нет — vanilla JS (ES5-стиль IIFE, как PinVideoBoard/PinRefBoard).

**Команды:** `node tools/dev-server.mjs` → http://127.0.0.1:8941/ (статика + POST /api/dev-save пишет data/db.js без токена; только localhost при DEV_MODE); `node tools/test-movies.mjs` — тесты парсера ссылок; `node tools/import-pinterest.mjs [--dry|--commit]` — импорт из Pinterest; `node tools/enrich-movies.mjs [--dry|--commit|--all]` — автозаполнение описаний/обложек из Википедии.

**Точки входа:** `index.html` → `js/app.js` (приложение) → `js/movies.js` (парсеры + резолверы Wikidata SPARQL / Wikipedia REST — единый модуль для браузера и node через window-шим), `js/api.js` (GitHub Contents API: токен, sha-guard), `data/db.js` (данные — глобал `window.__PFB_DATA`, коммитится сайтом).
