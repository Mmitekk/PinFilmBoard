Решения и допущения

  • Кинопоиск не парсится (SSO-стена подтверждена пробами) — маппинг через Wikidata P1713 как попытка + ручной путь «название → Википедия»; это единственный честный вариант для статического сайта.
  • IMDb — через Wikidata P345 (проверено: уникальный результат, ru-описание, sitelink → REST summary с постером).
  • Постеры — исходные миниатюры Википедии (330px): попытка апгрейда до 480px дала 404 у части файлов — откатил и починил уже сохранённые URL.
  • Описания длинные хранятся целиком; в карточке — clamp 2 строки, в модалке — целиком.
  • Секция «смотреть-позже» и др. PinVideoBoard-задачи не переносились: PinFilmBoard — отдельный сервис, единая доска «Фильмы».

Открытые вопросы и риски

  • Часть карточек с латинскими названиями без описания (пины-скриншоты IMDb, у которых resolve не удался в момент импорта) — лечится кнопкой «Википедия» в редакторе.
  • Неофициальный Pinterest API и SPARQL WDQS — лимиты возможны; в инструменте ретраи.
  • WDQS CORS в браузере: Wikidata документирует ACAO, но в живом браузере не проверено (node-проверки прошли); при проблеме — цепочка всё равно работает через поиск Википедии.
